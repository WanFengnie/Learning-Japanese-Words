# 新标日单词记忆

《新版中日交流标准日本语》（初级～高级，第 1～104 课）词汇记忆工具
纯前端，无依赖、无构建

## 功能

- 按课次 / 生词表浏览、搜索词汇
- 卡片学习：记住 / 忘记 / 掌握三档判定
- 测验：多种题型（日→中 中→日 听音辨义 汉字→假名 假名→汉字 输入假名）可选每轮词数
- 复习：待巩固与已掌握分池，按间隔时间排序复习；支持做题、翻卡、列表
- 进度保存在浏览器 `localStorage`，支持导出 / 导入备份
- 浏览器语音朗读（Web Speech API）


## 使用
联网使用：打开 https://japanese.cruxs.net/ 即可

本地使用：下载后用浏览器打开 `index.html` 即可

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构 |
| `style.css` | 样式 |
| `app.js` | 应用逻辑 |
| `data.js` | 词汇数据，条目格式 `[假名, 表记, 词性, 释义]` |
