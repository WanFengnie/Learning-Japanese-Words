# 新标日单词记忆

《新版中日交流标准日本语》（初级～高级，第 1～104 课）词汇记忆工具
纯前端，无依赖、无构建

## 功能

- 按课次 / 生词表浏览、搜索词汇
- 卡片学习：记住 / 忘记 / 掌握三档判定
- 测验：多种题型（日→中 中→日 听音辨义 汉字→假名 假名→汉字 输入假名）可选每轮词数
- 复习：待巩固与已掌握分池，按间隔时间排序复习；支持做题、翻卡、列表，可组合筛选课程、掌握时间和最近复习时间，支持最近 10 分钟、30 分钟、1 小时、今天及自定义时间范围，另可筛选尚无复习记录、今天未复习的词
- 进度保存在浏览器 `localStorage`，支持导出 / 导入备份
- 掌握时间记录最近一次从未掌握变为已掌握的时间，包括学习卡片判为掌握、积分达标和测验全部答对；保持掌握不会更新时间，降级后重新掌握会更新；旧记录无法还原历史掌握时间，仍可通过全部时间查看
- 最近复习时间在复习答题或卡片判级时更新，浏览卡片或词表不计入；旧记录无法还原历史复习时间，显示为尚无复习记录
- 复习做题按所选的 10／20／30／全部词出题，不受翻卡每轮 12 词的限制；页面分别显示符合筛选的词数、本轮词数和题数
- 浏览器语音朗读（Web Speech API）


## 使用
联网使用：打开 https://japanese.cruxs.net/ 即可

本地使用：下载后用浏览器打开 `index.html` 即可
